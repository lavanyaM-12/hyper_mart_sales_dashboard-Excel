# Hyper Mart Sales Dashboard | Excel Project

## 📌 Project Overview

The Hyper Mart Sales Dashboard is an Excel-based data analytics project designed to analyze sales performance and profitability across different regions, customer segments, states, and product categories.

The dashboard uses interactive-style charts to present business data visually and make sales trends easier to understand.

## 🎯 Project Objectives

- Analyze month-wise sales performance.
- Compare sales across different regions and states.
- Understand sales distribution across customer segments.
- Identify top-performing product subcategories by profit.
- Compare sales across product categories.
- Present business insights through a visual dashboard.

## 🛠️ Technologies Used

- Microsoft Excel
- Pivot Tables and Pivot Charts, if used
- Excel charts and data visualization
- Data cleaning and analysis, if performed

## 📊 Dashboard Features

- Month-wise Sales Analysis
- Region-wise Sales
- Top 4 Subcategories by Profit
- Segment-wise Sales
- Top 5 States Overview
- Category-wise Sales

## 📂 Workbook Structure

- **People:** People-related supporting data
- **Orders:** Order and sales data
- **Returns:** Product return information
- **Dashboard:** Sales visualizations and summary charts

## 💡 Business Value

This dashboard helps users explore sales trends, compare regional performance, identify profitable product areas, and support data-driven business decisions.
